# Tags: Smeltable Items

[![](https://badges.moddingx.org/modrinth/versions/tags-smeltable-items)](https://modrinth.com/datapack/tags-smeltable-items)

### What
This datapack simply adds three **item tags**:
- `#smeltable:via_smelting` - items that can be smelted in the furnace
- `#smeltable:via_blasting` - items that can be blasted in the blast furnace
- `#smeltable:via_smoking` - items that can be smoked in the smoker

The `#smeltable:via_smelting` tag includes all items a normal furnace supports, including those that can also go into the blast furnace or smoker.

These tags are based on the **vanilla** smelting recipes and won't account for any custom smelting recipes added by other datapacks or mods.

### Why
The tags provided by this datapack are useful for filtering/routing items.
For example, I use the `#smeltable:via_smelting` tag to make sure my super smelter furnaces don't get blocked by non-smeltable items if I accidentally put them in the input chest (I use Classic Pipes to route items which allow filtering by tags).

### When
The datapack is updated automatically as soon as a new version of Minecraft Java Edition is released.
